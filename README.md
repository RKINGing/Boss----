# BOSS直聘自动沟通助手

![version](https://img.shields.io/badge/version-0.3.0-blue)
![platform](https://img.shields.io/badge/platform-Tampermonkey-green)
![browser](https://img.shields.io/badge/browser-Chrome%20%7C%20Edge-informational)
![license](https://img.shields.io/badge/license-MIT-green)

一个运行在 Tampermonkey / 篡改猴中的 BOSS 直聘网页辅助脚本。

脚本在职位搜索结果页按条件筛选岗位，自动进入职位详情、点击“立即沟通”、打开聊天页，发送自定义问候语，并可继续发送图片简历。发送完成后自动返回岗位列表，按设定的间隔处理下一个岗位。

> 本项目仅用于个人求职效率辅助，不绕过验证码、不破解登录或风控机制。使用前请确认符合 BOSS 直聘平台规则，并自行承担账号使用风险。

---

## 功能特性

- 在职位列表页自动选择符合条件的岗位
- 支持自定义问候语，可使用 `{jobName}`、`{company}`、`{salary}`、`{bossName}` 占位符
- 支持 BOSS 常用语模式
- 支持在问候语之后自动发送图片简历
- 支持岗位关键词筛选
- 支持薪资范围筛选
- 支持城市 / 地区筛选
- 支持经验要求筛选
- 支持学历要求筛选
- 支持公司筛选和公司黑名单
- 支持 Boss 活跃度筛选
- 支持跳过已沟通 HR
- 支持随机发送间隔
- 支持聊天页渲染超时重试
- 支持沟通次数提醒弹窗处理
- 支持列表耗尽后自动刷新续跑
- 支持沟通记录导出与清理
- 支持调试日志

## 适用页面

脚本匹配以下 BOSS 直聘网页路由：

```text
https://www.zhipin.com/web/geek/jobs*
https://www.zhipin.com/web/geek/job*
https://www.zhipin.com/web/geek/recommend*
https://www.zhipin.com/web/geek/chat*
```

面板会在职位列表页和聊天页显示。

## 安装

### 1. 安装浏览器脚本管理器

推荐使用以下任意一种：

- Tampermonkey / 篡改猴
- Violentmonkey

### 2. 安装脚本

1. 打开 Tampermonkey 管理面板。
2. 点击“添加新脚本”。
3. 删除编辑器中的默认内容。
4. 把 `boss-auto-apply.user.js` 的全部内容粘贴进去。
5. 按 `Ctrl + S` 保存。

### 3. 确认版本

打开 BOSS 直聘页面后，右侧面板顶部应显示：

```text
0.3.0
```

如果显示的版本不是 `0.3.0`，说明脚本没有替换成功。

## 快速开始

1. 登录 BOSS 直聘网页版。
2. 进入职位搜索结果页，先用 BOSS 页面自身的筛选功能设置好关键词、城市、薪资、经验等基础条件。
3. 打开右侧“BOSS自动沟通”面板。
4. 在“打招呼配置”中选择问候语模式：
   - 常用语：使用 BOSS 常用语。
   - 手动输入：填写自定义语句。
5. 在“图片简历”区域选择图片，并勾选“发送问候语后自动发送图片简历”。
6. 在“岗位筛选”区域填写必须包含关键词、排除关键词、薪资范围、城市、经验、学历等条件。
7. 在“运行策略”区域设置发送间隔、等待上限、聊天重试次数、最大沟通数等参数。
8. 点击“启动”。

脚本会自动执行以下流程：

```text
职位列表
  -> 筛选岗位
  -> 点击“立即沟通”
  -> 进入聊天页
  -> 发送问候语
  -> 发送图片简历
  -> 返回职位列表
  -> 等待随机间隔
  -> 处理下一个岗位
```

## 配置说明

### 打招呼配置

| 配置项 | 说明 |
| --- | --- |
| 常用语 | 使用 BOSS 页面提供的常用语 |
| 手动输入 | 使用自定义问候语 |
| 接口返回 | 从自定义接口获取问候语，支持参数、请求头和请求体模板 |
| 问候文本 | 支持 `{jobName}`、`{company}`、`{salary}`、`{bossName}` 占位符 |

### 图片简历

| 配置项 | 说明 |
| --- | --- |
| 图片文件 | 本地选择 JPG、PNG、WebP 图片 |
| 自动发送图片简历 | 问候语发送成功后，继续发送图片 |
| 清除图片 | 删除浏览器本地保存的图片 |

图片保存在浏览器 IndexedDB 中，不会上传到脚本作者或第三方服务器。

超过 3MB 的图片会自动压缩为 JPEG。带透明通道的 PNG / WebP 也会转换成 JPEG 后再发送。

### 岗位筛选

| 配置项 | 说明 |
| --- | --- |
| 必须包含关键词 | 每行一个，命中任意一个即可 |
| 排除关键词 | 每行一个，命中任意一个就跳过 |
| 薪资下限 | 单位 K，例如 15 表示 15K |
| 薪资上限 | 单位 K，例如 30 表示 30K |
| 允许面议 | 薪资筛选时是否允许“面议”岗位 |
| 城市 / 地区关键词 | 每行一个，命中任意一个即可 |
| 经验要求 | 例如 `3-5年`、`经验不限` |
| 学历要求 | 例如 `本科`、`大专` |

筛选采用两段式逻辑：

1. 列表阶段：排除词、明显不符合的薪资等条件会直接跳过。
2. 详情阶段：列表信息不足时，进入详情页后再次复核关键词、城市、经验、学历和薪资。

### 运行策略

| 配置项 | 说明 |
| --- | --- |
| 跳过已沟通 HR | 根据本地记录跳过已联系过的岗位 |
| 收集已打招呼岗位 | 保存已沟通岗位信息 |
| 列表耗尽后自动刷新 | 当前列表处理完后刷新页面继续 |
| 最小间隔 | 两个岗位之间的最小等待秒数 |
| 最大间隔 | 两个岗位之间的最大等待秒数 |
| 等待上限 | 列表页、详情页、聊天页等待超时秒数 |
| 聊天重试次数 | 聊天界面渲染失败后的重新点击次数 |
| 最大沟通数 | 本轮最多沟通多少个岗位，0 表示不限制 |
| 列表刷新上限 | 最多刷新多少次列表，0 表示不限制 |

### 公司筛选与黑名单

| 配置项 | 说明 |
| --- | --- |
| 公司筛选模式 | 全量匹配、部分匹配、正则匹配 |
| 公司筛选值 | 留空表示不过滤 |
| 公司黑名单 | 支持多条规则，命中任意一条即跳过 |

### Boss 活跃度筛选

支持 BOSS 内置活跃度选项，也可以添加自定义活跃度文本。

## 工作原理

脚本使用跨页面状态机保存运行进度：

```text
list -> chat -> returning -> list
```

| 阶段 | 说明 |
| --- | --- |
| list | 在职位列表页扫描岗位卡片并筛选 |
| chat | 在聊天页发送问候语和图片简历 |
| returning | 发送完成后返回职位列表 |
| list | 恢复列表位置，继续处理下一个岗位 |

运行状态保存在 `localStorage` 中，因此页面跳转或刷新后可以恢复。

岗位记录和图片简历保存在 IndexedDB 中。

岗位匹配同时参考：

- 页面 DOM 卡片
- BOSS 列表接口数据
- 职位详情接口数据
- 页面详情 DOM

薪资等字段优先使用接口明文，避免 BOSS 页面私有区字体导致识别错误。

## 图片简历说明

- 图片只在本地浏览器中保存。
- 图片通过 BOSS 聊天页自己的上传控件发送。
- 如果问候语已经发送成功，但图片没有被页面确认发送，脚本会记录警告并继续下一个岗位，不会卡住整个队列。
- 如果勾选“自动发送图片简历”但没有选择图片，启动时会提示先选择图片。

## 常见问题

### 面板没有出现

确认以下事项：

1. 脚本已经保存并启用。
2. 当前页面是 BOSS 职位列表页或聊天页。
3. Tampermonkey 中脚本版本为 `0.3.0`。
4. 浏览器没有禁用脚本管理器。

### 启动后提示“请先选择图片”

在“图片简历”区域选择一张图片，然后再勾选“发送问候语后自动发送图片简历”。

### 聊天界面提示渲染等待超时

脚本会自动返回职位列表并重新点击同一岗位，重试次数由“聊天重试次数”控制。

如果多次重试仍然失败，可以适当增加“等待上限”。

### 图片没有发送成功

可能原因：

- BOSS 聊天页暂时没有渲染上传控件
- 图片体积过大
- 当前账号或会话不支持发送图片
- BOSS 页面结构发生变化

可以打开调试日志，查看图片发送阶段的记录。

### 提示“今日沟通次数已用完”

脚本会暂停，不会继续强行沟通。请等待限制解除或更换账号策略。

### 会不会触发账号风控

自动沟通属于批量操作，任何自动化脚本都可能触发平台的安全策略。

建议：

- 使用较大的发送间隔
- 设置合理的最大沟通数
- 不要在短时间内频繁运行
- 出现验证码或安全验证时立即暂停
